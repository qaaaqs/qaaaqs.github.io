Personal Data Sync

Personal Data Sync は、作者が自分自身の Google アカウントのデータを自分の端末から読み書きするためだけに作った、個人用の非公開ツールです。一般の方への提供・配布は行っていません。

プライバシーポリシー ・ 利用規約

概要

  • 利用者は作者本人のみです。
  • Google OAuth 2.0 で作者本人の Google アカウントに接続し、Google Tasks（タスクの読み書き）と Google Health API の睡眠データと、睡眠の記録に使う心拍・心拍変動・血中酸素などの健康指標（いずれも読み取りのみ）にアクセスします。
  • Web サービスやサーバーとしては動作しておらず、作者が管理する端末上でのみ実行されます。

プライバシーポリシー

  • 取得するデータ: 作者本人の Google Tasks のタスク情報と、作者本人の睡眠データと睡眠の記録に使う健康指標（心拍・心拍変動・血中酸素など）のみです。本人以外の方のデータを取得・保存することはありません。
  • 利用目的: 作者本人のタスク管理と睡眠記録の整理、およびそれらに関する作者本人の作業補助のためにのみ利用します。
  • 保存場所: 取得したデータ（およびそこから作成した記録）は、作者本人が管理する端末に保存し、作者本人の端末間でのみ同期します。認証情報はツールを実行する端末にのみ保存します。
  • 保護方法: 認証情報は、実行する端末上で作者本人のみが読み書きできるアクセス権限に制限して保存します。端末間の同期は暗号化された通信で、作者本人の端末どうしの間でのみ行います。
  • 外部への送信: 作者は作業補助に AI アシスタント（Anthropic 社の Claude）を利用しており、作者がその場で指示したときに、タスク情報や睡眠記録の一部が Anthropic 社へ送信されることがあります。送信されたデータは Anthropic 社の規約と作者のアカウント設定に従って扱われます。これ以外の第三者へ送信・共有することはありません。
  • 販売・広告: 取得したデータを販売したり、広告に利用したりすることはありません。
  • 削除: 作者はいつでも Google アカウントの設定から本ツールのアクセス権を取り消せます（以後の取得が止まります）。すでに保存した記録は、作者本人の各端末から削除します。Anthropic 社へ送信済みのデータは、同社の保持・削除の条件に従います。アクセス権の取り消しによって Google 側の元データが削除されることはありません。
  • ポリシーの遵守: Google API から取得した情報の利用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use 要件を含む）および Google Health API Developer and User Data Policy（Limited Use 要件を含む）に従います。
